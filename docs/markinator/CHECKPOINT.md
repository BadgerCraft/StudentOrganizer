## Completed category-change recovery batch

Before editing, the failure was reproduced at `b27954a` in both a service regression and actual Chromium. After an authorized replacement of the T category ID, Save now and Resolve newer manual mark conflict both failed with “Review judgments for every current assessment category.” The conflict panel could not open; pending feedback remained only in memory. Existing marks were unchanged. Category-code uniqueness requires deleting/replacing the old row for an ID-replacement fixture; ordinary removal uses a tombstone.

Draft saving now validates against the session's pinned category snapshot, recovered from its existing baseline for legacy sessions. It preserves all pending and saved content even when categories disappear. The UI names the original categories and explicitly reviews the pinned rubric before any reconciliation. A teacher can retain a judgment only across compatible KTAC/maximum/scale definitions, or retain the original feedback in visible recovery history and begin the current category unassessed. Changed/removed originals remain in the session, audit history and full backups. No silent mapping, removal of feedback, conversion of marks or grade override is introduced.

Reconciliation and its audit record share one authorized transaction and reject changed session versions or review tokens. Reconciliation does not refresh the official baseline. Accepting a newer manual mark remains a separate explicit review, and `refreshBaseline` can no longer rebuild/drop category judgments. Opening a revision also preserves the prior category snapshot and judgments. Backup validation supports missing historical category rows only through validated, same-assessment session snapshots, including finalized-history references; orphaned official results still fail validation.

If a required pinned-rubric category is absent, the saved original draft stays recoverable and finalization is blocked. The UI directs the teacher to Import/Export → Download Full Backup and explains that the required categories must be restored in an authorized context before another review. **The existing assessment screen has no category editor; that repair may require assistance.** This batch does not add an assessment editor or change rubric mappings. Recovery history is bounded to 200 retained judgments; reaching the limit fails without discarding the saved draft.
