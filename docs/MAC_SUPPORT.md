# Mac test packages

F-006 approved October 1, 2026. This branch adds per-architecture Mac disk-image and archive builds. Electron 44 requires macOS 13 or later. CI uses native Apple Silicon and Intel macOS 15 runners rather than presenting cross-compilation as native launch evidence.

Run `npm run package:mac -- --arm64 --publish never` on Apple Silicon or replace `--arm64` with `--x64` on Intel. The recovery smoke runs only on ephemeral GitHub Mac runners, because it deliberately replaces the fictional database. Do not run it against a teacher installation. The test mounts the actual DMG, copies the app, detaches the image, launches the copied app, enters a fictional observation, photo and assessment mark with feedback, saves a full backup, rejects an invalid restore, confirms recovery after later edits, and reopens the app to check persistence. It also extracts the exact ZIP and independently repeats the flow. Evidence, source ID, architecture, screenshots and checksums are uploaded alongside the packages for 90 days.

The PR build explicitly enables credential-free ad-hoc signing because electron-builder v26 normally skips all signing on pull requests; a preceding check requires the ad-hoc identity, and the workflow supplies no signing credentials. The bundles use an ad-hoc test signature, not an Apple Developer ID certificate or notarization. CI launch has no downloaded-file quarantine and does not establish what a colleague's Mac or school policy will allow. Do not ask users to disable protection. Wider distribution/signing and release remain separate decisions. No signing account or subscription is created.

The application ID and local data directory are unchanged. Copying the app to another device does not copy its records. Use Import/Export to save a full JSON backup and restore it on the destination. Restoration replaces destination records after whole-file validation; independently edited devices are not merged. Preserve a destination backup first. No automatic synchronization is included.

The script covers participation, mark entry, photo selection and backup recovery, but coverage is only established when the actual package job passes on that source. Native file-picker interaction, quarantine/Gatekeeper and school-managed Macs still need device checks. Physical iPad validation remains separate. See IPAD_SUPPORT.md and the current work-order report for observed results.

Primary documentation checked October 1: [Electron 44 minimum macOS](https://www.electronjs.org/blog/electron-44-0), [electron-builder v26 Mac configuration](https://www.electron.build/v26/docs/mac/), [GitHub runner architectures](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).
